# 연구년 선생님 AI 연구 설계 대시보드

클로드에서 이어서 개발하거나 다른 호스팅에 배포할 수 있는 독립 React + Vite 프로젝트입니다.

## 먼저 확인할 것

- `app/`, `components/`, `main.tsx`: 수정 가능한 전체 앱 소스
- `public/`: 강의 슬라이드, 공식 브랜드 이미지, 최종보고서 HWPX 원본, Apps Script 예제
- `docs/`: 빌드가 완료된 배포 파일. **폴더 안의 파일과 하위 폴더를 함께** 배포하세요.
- `CLAUDE_HANDOFF.md`: 클로드에 전달할 작업 지침

압축파일에는 설치 폴더, 계정 인증정보, 배포용 비밀키가 없습니다.

## 포함된 기능

1. 22개 교사별 연구주제 카드와 동일한 1~7단계 연구실
2. 강사용 가상 연구 「한국형 사회정서교육을 위한 마음데이터 수집 웹앱 개발 및 적용 연구」: 연핑크 카드, 예시 자료와 분석
3. 교사별 카드 색상 선택, 브라우저 내 기록 저장
4. 연구 키워드 워드클라우드와 마우스 반응 EchoText 모션
5. GPT·Gemini·Claude 연결 및 프롬프트 복사, Padlet 결과 공유 링크
6. Google Apps Script 수집 도구 예제와 GitHub Pages 실습 안내
7. 제공받은 최종보고서 양식에 맞춘 작성 화면 및 원본 HWPX 다운로드
8. 50분 × 3차시, 총 150분 공통연수
   - 1차시: AI를 활용한 학습분석연구
   - 2차시: 내 연구 대시보드
   - 3차시: 바이브코딩으로 웹앱만들기

## 실행 및 수정

Node.js 22.13 이상이 필요합니다. `package.json`에 지정된 pnpm을 사용하세요.

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm dev
```

수정 후 배포 파일 만들기:

```bash
pnpm build
```

결과는 `docs/`에 생성됩니다. 로컬 확인:

```bash
pnpm preview
```

`index.html`을 더블클릭하는 방식의 단일 HTML 앱은 아닙니다. 개발 서버 또는 정적 호스팅에서 여세요.

## 배포

### GitHub Pages

프로젝트 전체를 GitHub 저장소에 올리고 Settings → Pages에서 Branch를 선택한 뒤 `main`의 `/docs`를 게시 폴더로 설정합니다. 이미 빌드된 `docs/`가 포함되어 있으므로 소스를 바꾸지 않았다면 다시 빌드할 필요가 없습니다.

### 다른 정적 호스팅

완성된 `docs/` **내용 전체**를 배포하거나, 소스 연결 후 빌드 명령 `pnpm build` / 출력 폴더 `docs`로 설정합니다. 화면 이동은 해시 경로이므로 별도 서버 라우팅이 필요하지 않습니다. 자산 경로는 상대 경로입니다.

## 데이터 저장 범위

연구 메모, 카드 색상, 실습 진행 상태는 각 브라우저의 localStorage에 저장됩니다. 계정 로그인·중앙 서버 저장·여러 기기 간 동기화는 없습니다. 기존 사이트에서 개인이 입력한 기록은 이 ZIP에 포함되지 않으며, 주소가 바뀌면 자동으로 이동하지 않습니다. 가상 시연 자료만 소스에 포함되어 있습니다.

## 확인한 범위

2026-09-20 최신 원격 소스와 대조했습니다. TypeScript 검사와 정적 배포 빌드, 보고서 양식·슬라이드·차시명·강사 샘플 포함 여부를 확인했습니다. 내보내기 후 전체 화면의 브라우저 조작 검사는 수행하지 않았습니다.
